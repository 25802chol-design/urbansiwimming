# 🏊‍♂️ 어반수영장(URBAN SWIM) 마케팅 웹사이트

대회장에서 화제가 된 **블랙 & 핑크** 시그니처, **공인 자격증 강사진의 100% 실전 생존수영 교육**, 그리고 락스를 전혀 쓰지 않는 **100% 친환경 해수풀 시스템**을 고객 관점에서 설득력 있게 전달하는 반응형 마케팅 웹사이트입니다.

---

## 🌟 주요 특징 및 최신 반영 사항
1. **공식 브랜드 로고 적용**:
   - 공식 원형 블루 & 블랙 URBAN 로고 헤더, 푸터, 파비콘 탑재
2. **[신규] 생존수영 전문 교육 섹션**:
   - 공인 생존수영 지도 자격증 보유 강사진의 실전 교육
   - 체온 유지 원형 집단 부유(Huddle) 훈련
   - 실제 해상 구명뗏목(라이프래프트) 승하선 및 비상 탈출 모의 훈련 실습
   - 실제 4장 실습 현장 포토 그리드 (아이들 프라이버시 보호 정밀 모자이크 적용)
3. **어린이 & 성인 & 온가족 맞춤 커리큘럼**:
   - **어린이 수영**: 기본 1:5 소수정예 (단, **봉선점만 1:4 단독 운영**), 수강 대상 **6세 ~ 중학생**, 주니어 대회반
   - **성인 수영**: *(지점별로 프로그램 및 시간표에 차이가 있습니다)* 명시 및 정돈된 영법 교정
   - **온가족 친환경 수영장**: 어린이도 성인도 안심하고 다닐 수 있는 깨끗하고 따뜻한 32℃ 친환경 해수풀 가치 전달
4. **광주·나주 5개 거점 지점 상세 도로명 주소 & 직통 연결**:
   - **빛가람점**: 전남광주통합특별시 나주시 빛가람로 838 주4동 (`0507-1382-7375`)
   - **봉선점**: 전남광주통합특별시 남구 봉선로52번길 14 (주월동) (`010-6747-9764`) - *1:4 밀착 수업*

   - **각화점**: 전남광주통합특별시 북구 동문대로248번길 48 (`0507-1367-9764`)

## 🚀 확인 및 실행 방법

### 방법 1. 즉시 브라우저에서 열어보기 (무설치 프리뷰)
- 바탕화면의 [**`홈페이지 제작`**](./) 폴더에 있는 [`index.html`](./index.html) 파일을 마우스로 **더블 클릭**하시면 웹브라우저에서 모든 공식 로고, 생존수영 실습 사진(모자이크), 5개 지점 주소 및 동작을 즉시 확인하실 수 있습니다.

### 방법 2. Next.js 개발 서버 구동 (App Router)
터미널에서 아래 명령어를 순서대로 실행하세요:

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하시면 Next.js로 렌더링되는 웹사이트를 확인하실 수 있습니다.
